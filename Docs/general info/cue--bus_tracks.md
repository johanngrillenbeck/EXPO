# What are "Bus"-Tracks again?

Reaper does not supply track types, which is a good thing. But for the scripts to work, and for some human readable navigation in our projects, I have introduced track prefixes in my other script collections MCTM and CURSE, which we will also use here.

"B" is for Bus Tracks.
In terms of our script logic, a track is a "Bus"-Track if it has the prefix "B " (B + Space) followed by an arbitrary name.

As an example, here is an excerpt of my collection of bus tracks:

| Track name in Reaper | Full name      |
| -------------------- | -------------- |
| B HiWW               | High Woodwinds |
| B MidWW              | Mid Woodwinds  |
| B LoWW               | Low Woodwinds  |
| B HiBr               | High Brass     |
| B MidBr              | Mid Brass      |
| B LoBr               | Low Brass      |
| ...                  |                |
| B ArpSynth           | Arp Synth      |
| B PadSynth           | Pad Synth      |
| ....                 |                |
| B HiStr              | High Strings   |
| B MidStr             | Mid Strings    |
| B LoStr              | Low Strings    |
