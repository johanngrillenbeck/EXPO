# Dependencies

## ReaImGui

[ReaImGui](https://codeberg.org/cfillion/reaimgui) is distributed via ReaPack through the default ReaTeam Extensions repository.

##  Ultraschall API
[The Ultraschall API](https://mespotin.uber.space/Ultraschall/US_Api_Functions.html) is used to manage export settings, because they have come up with an elegant way to store and apply render settings, using what they call "Render Tables". Since Reaper's behavior and possible parameters might change in the future, we should collaborate rather than reinvent the wheel individually, so I am gladly referencing the Ultraschall API here. Also ... Render Tables are way more complex than a wheel.
