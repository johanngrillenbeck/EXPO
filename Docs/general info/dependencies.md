# Dependencies

## ReaImGui

[ReaImGui](https://codeberg.org/cfillion/reaimgui) is distributed via ReaPack through the default ReaTeam Extensions repository.

##  Ultraschall API
[The Ultraschall API](https://mespotin.uber.space/Ultraschall/US_Api_Functions.html) is used by the pre-mix STEM action only to build REAPER's encoded WAV render-format string. Render source, bounds, channels, sample rate, output paths, and render execution are configured through REAPER's native project API. Other actions may still have separate Ultraschall dependencies.
